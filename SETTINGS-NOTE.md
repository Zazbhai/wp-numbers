# Settings

Original source files are included without code changes. Private credentials, proxy passwords, browser sessions, dependencies and generated output are excluded.

The `.env.example` file lists empty credential fields; no private keys are included. Keep real credentials in secure runtime environment settings, not committed files.

This is a source export, not a verified VPS deployment package. The current monitor and linking bridge are preview-only. Lasting monitoring requires a persistent external browser host and changes to sync linking data with the hosted app. Managed Lovable credentials cannot simply be transferred to an independent host.
